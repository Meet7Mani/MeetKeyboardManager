# MeetKeyboardManager

A lightweight iOS keyboard manager that adds a Done button to text fields and text views and automatically adjusts the view when the keyboard appears.

## Features

- Adds a Done button to `UITextField`
- Adds a Done button to `UITextView`
- Automatically adjusts the view when the keyboard appears
- Restores the view when the keyboard disappears
- Supports iOS 15+
- Works with UIKit

## Requirements

- iOS 15.0+
- Swift 5.0+
- UIKit

## Installation

### CocoaPods

Add the following to your `Podfile`:

```ruby
pod 'MeetKeyboardManager'
